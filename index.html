Quiz Board Engine

A zero-cost, zero-build, zero-CDN static web app that turns plain JSON files into playable quiz board games — Jeopardy, trivia bingo, and Family Feud-style ranked reveals — rendered through a vendored copy of Reveal.js.

Status: under construction. The board renderer lands in F3.

Running locally? The app needs an HTTP origin — file:// blocks ES module and JSON fetches. Use python3 -m http.server 8000.
